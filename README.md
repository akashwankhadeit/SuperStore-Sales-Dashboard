# SuperStore Sales Dashboard

An interactive Power BI dashboard to analyze SuperStore sales and business performance.

## Dashboard Insights
- Total Sales and Profit
- Monthly Sales Trends
- Category and Sub-Category Analysis
- Regional Performance
- Top and Bottom Products
- Customer Segment Analysis

## Tools Used
- Microsoft Power BI
- DAX
- Power Query

- Dashboard (.pbix)
- Dataset (.csv)
